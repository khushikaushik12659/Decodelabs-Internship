#Python To-Do List

Description-

This project is a simple Python-based To-Do List application.

It allows users to:

Add tasks
View all tasks
Exit the program

The project uses Python lists, user input, loops, and conditional statements.

How to Run

1. Make sure Python 3 is installed on your computer.
2. Open the project folder.
3. Run the following command:

python todo.py

Technologies Used

- Python 3
